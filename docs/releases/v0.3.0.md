# cc: v0.3.0

Context is now cc:, a local shelf for files, folders, links, images, and text.

## Changes

- Rename the visible product and app bundle to `cc:` and `cc.app`, with a new
  icon. Existing shelf data and settings remain available.
- Use the Menu Bar shelf by default, or choose Notch in Settings on a display
  with a notch. Both show the same saved items and controls.
- Add Settings for shelf location, configurable keyboard shortcuts, agent setup,
  and update checks. Shortcut changes and the shelf location survive restarts.
- Include the `context` CLI and optional `context-handoff` skill installer for
  adding, listing, and reading local shelf items from Codex or Claude.
- Keep items and their managed copies in the shelf after copying them to a
  folder. Removing or clearing shelf items leaves the original files and
  exported copies in place.
- Verify Sparkle update archives with Ed25519 signatures through the existing
  update feed.

## Distribution and compatibility

Requires macOS 26 or later on Apple Silicon or Intel. The DMG and ZIP contain
`cc.app`, its bundled CLI, the optional skill installer, and Sparkle.

The bundle identifier `work.hayashigoto.Context`, local store
`~/Library/Application Support/Context`, `context` CLI, `context-handoff` skill,
`context:` deep links, and GitHub release URLs remain compatible. The
command-line installer accepts both `Context.app` and `cc.app` and preserves a
migration backup when replacing the former app.

This release uses ad-hoc app signing and is not notarized by Apple. Sparkle's
archive signature is separate from Developer ID signing and Apple notarization.
macOS may block the first launch; use **System Settings → Privacy & Security →
Open Anyway** to allow it.
